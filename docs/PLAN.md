# Pomotato — Milestone Plan

Build order. Don't start a milestone until the previous one is PASS + reviewed.

Task numbers in `docs/tasks/` run as one sequence covering both milestone work and
off-plan work, so **task numbers and milestone numbers do not line up**. Tasks 001-003

  - [x] **Semantic tokens across the remaining UI.** DESIGN.md's premise is that new surfaces are dark-ready from the start so this milestone "can theme them by adding a single dark block instead of restyling them a second time". It was false when this milestone opened — 86 raw Tailwind palette classes sat in app code. Done: [006](tasks/006-timer-surface-tokens.md) the timer surface, [007](tasks/007-token-foundation-completion.md) the rest, with a repo-wide guard asserting zero raw palette across `app/`, `components/`, `hooks/` and `widgets/`. **Caveat:** 007's review (R-1) found four interactive boundaries still at the soft 1.36:1 `--border`, generated by the `outline` variant in `components/ui/button.tsx` — a dark block alone leaves them under 3:1 in both themes, so they need their own pass before the toggle.
  - [ ] **Visible light/dark toggle.** Required, not optional — she studies at night. Deferred here explicitly by DESIGN.md.
  - [ ] **Paper grain texture** at low opacity, produced procedurally (SVG/CSS) rather than shipped as an asset, which sidesteps licensing. Deferred here explicitly by DESIGN.md.
  - [ ] **A settings surface**, holding the theme controls above plus a timer gauge style preference. ([docs/tasks/008-settings-gauge-style.md](tasks/008-settings-gauge-style.md) — unblocked now 007 is closed; backend runs first, for the preference store.)
  - [ ] **Uploaded backgrounds.**
- [ ] **5. Ambient soundscape mixer** — layered loops, per-layer volume. CC0/properly licensed audio only.
- [ ] **6. Music embeds** — official embeds from pasted playlist URLs. No scraping, no unofficial APIs.
- [ ] **7. PWA + export/import** — installable PWA, JSON export/import. Sync is a later, separate milestone.
